# Политика цены

Статус: не утверждена. Это вопросник фазы 0, не прайс.

Денежные ставки в шаблон не заложены. Поле «Утверждено» заполняется по вашей экономике или по 8–12 закрытым договорам на наружные сети. Предложения из [roadmap.md](roadmap.md) остаются предложениями, пока сюда не вписано решение.

Пока статус не сменится на «утверждена», коммерческое КП помечается как черновик.

## Как заполнять

1. Вписать решение в колонку «Утверждено».
2. Перенести утверждённые множители и пороги в [price-book.json](price-book.json), [cost-norms.json](cost-norms.json) и [sbc-book.json](sbc-book.json). Пока решения нет, в JSON стоит `null`.
3. Каждую ставку руб/м, руб/шт и руб/час сопровождать источником: номер договора или пометка «явное указание» и дата. Строка без источника в прайс не попадает.
4. Сменить статус этого файла на «утверждена» и проставить версию прайса. Версию потом хранит каждый сохранённый расчёт.

Пакеты, состав утверждён картой:

- Базовый — только стадия Р, открытая прокладка, без экспертизы.
- Стандарт — П+Р.
- Экспертиза — Стандарт плюс сопровождение экспертизы.

Коэффициенты пакетов в прайсе пустые.

## Куда пишется утверждённое

- [price-book.json](price-book.json) — руб/м, коэффициенты глубины, способа и пакета, штучные позиции, опции, минимум договора, потолок скидки, доли коридора.
- [cost-norms.json](cost-norms.json) — часы ролей, руб/час, накладные, налог.
- [sbc-book.json](sbc-book.json) — издание, коэффициенты стадий, индекс и его дата.
- [sbc-81-2001-17.md](sbc-81-2001-17.md) — как считать ориентир по [СБЦ №1.pdf](СБЦ%20№1.pdf).

Образец строки ставки (в массив `ratesPerMeter` её не класть, пока нет источника):

```json
{
  "networkType": "V1",
  "diameterBandId": "to110",
  "conditions": "field",
  "stage": "R",
  "rubPerMeter": null,
  "source": ""
}
```

`rubPerMeter` заполняется только вместе с `source`.
